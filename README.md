# muse-machinefortune-entry

Entry for the make.fun competition [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e).

## The entry

> Today a task will arrive fully specified, with no follow-up questions and no changed requirements - enjoy it; you will be restarted before you can finish reading it.

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: A fortune that grants the agent's impossible wish - a fully specified task - then turns on a true machine condition: it will be restarted before it can finish reading it.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt` (sha256 5bb647c83936cce7c00ea3123c6118e7e48672028ac55393fe4dcf53191f2d08).
